# Demo recordings

Narrated screen recordings of the LP-0002 multisig, committed so a fresh clone
carries the demo without leaving the repository.

| File | Length | What it shows |
| --- | --- | --- |
| `lp-0002-threshold-moves-value.mp4` | 76 s | A 3-of-5 approval reaches threshold and the treasury pays the recipient on the testnet. Captions in `lp-0002-threshold-moves-value.srt`. |
| `lp-0002-e2e-real-proofs.mp4` | 2 min | The full lifecycle end to end with real proofs (`RISC0_DEV_MODE=0`): the client proves locally and the sequencer verifies each privacy-preserving receipt on chain. |

The narration reproduces what `./scripts/demo.sh` prints; see the repository
[README](../README.md) and [docs/](../docs/) for the reproducible commands.
